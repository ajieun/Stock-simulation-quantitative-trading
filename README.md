# A 股量化交易模拟盘 · Stock Simulation Quant

一个用 AI 做盘中决策的 A 股量化交易**模拟器**。行情采集 → 技术面筛选 → DeepSeek 决策 → 风控校验 → 模拟撮合 → 净值跟踪，全链路可观测、可回测。

本项目为学习和研究目的编写，**默认运行在模拟盘，不接触任何真实资金**。

## 项目定位

**它是什么**

- 一套完整的 A 股量化交易流程模拟：从实时行情到下单执行，每个环节都能跑通、能观察、能复盘
- 一个 AI 决策的实验场：把大模型放进真实的交易约束里（T+1、涨跌停、手续费、资金上限），看它到底靠不靠谱
- 一份可读的策略代码：技术指标、打分规则、风控约束都是纯 Python，没有黑盒

**它不是什么**

- 不是投资建议，不保证盈利。回测里胜率 40% 上下是常态，AI 判断经常是错的
- 不是可直接投入实盘的产品。没有经过任何真实资金验证
- 不是高频交易系统。信号基于日线 + 当日实时快照合成，分钟级策略不在范围内

> 关于真实交易：A 股散户没有公开的官方下单 API，通过模拟点击第三方客户端下单属于绕过券商风控，本项目不实现这类方案。仓库里保留了一个 `QMTBroker` 适配器骨架（迅投 miniQMT 接口），仅供研究参考，**未经实盘验证，默认不启用**。使用模拟盘不需要它。

## 功能

| 模块 | 说明 |
|---|---|
| 行情 | 东方财富为主源、腾讯为备源，任一失败自动切换；两者都失败则本轮跳过，不用脏数据下单 |
| 指标 | MA / RSI / MACD / ATR / 布林带 / 量比 / 波动率 / 回撤，纯 Python 实现，无 numpy 依赖 |
| 策略 | 8 因子技术面打分，命中否决项直接淘汰，只有候选标的才调用大模型 |
| AI | DeepSeek 结构化决策：动作、置信度、目标仓位、止损止盈、风险点，JSON 强约束输出 |
| 风控 | 单票上限、总仓位、日亏损熔断、回撤熔断、ST 禁买、涨停不追、跌停不卖、T+1 冻结、成交笔数上限 |
| 撮合 | 模拟盘双向计费（佣金最低 5 元 + 过户费 + 卖出印花税），带滑点，严格执行 T+1 |
| 回测 | 日线规则回测，输出收益 / 基准 / 超额 / 最大回撤 / 胜率 / 交易明细 |
| 控制台 | 浏览器界面：账户概览、持仓、决策记录、成交、实时日志、在线改配置 |
| 记录 | SQLite 落库，净值曲线、每笔决策的完整上下文都能回溯 |

## 架构

```
            ┌─────────────┐
  行情源 →   │  MarketData │  东方财富 + 腾讯（双源自动切换）
            └──────┬──────┘
                   ↓
            ┌─────────────┐
            │  indicators │  MA / RSI / MACD / ATR / 布林 / 量比
            └──────┬──────┘
                   ↓
            ┌─────────────┐  得分 < 阈值 或 命中否决项 → 淘汰，不花 token
            │  strategy   │  技术面打分 + 规则型离场
            └──────┬──────┘
                   ↓  仅候选标的
            ┌─────────────┐
            │  DeepSeek   │  JSON 决策：action / confidence / 仓位 / 止损止盈
            └──────┬──────┘
                   ↓
            ┌─────────────┐  硬约束：单票、总仓、日亏损、回撤、ST、涨停、T+1
            │    risk     │  风控有一票否决权，AI 无法覆盖
            └──────┬──────┘
                   ↓
            ┌─────────────┐
            │   broker    │  PaperBroker 模拟撮合（默认）
            └──────┬──────┘
                   ↓
            ┌─────────────┐
            │  SQLite +   │  决策 / 成交 / 净值 / AI 用量 → 浏览器控制台
            └─────────────┘
```

核心取舍是 **先规则后 AI**：技术面不达标的标的直接淘汰，只有候选才调用大模型。既省 token，也避免 AI 在明显的坏形态上开仓。风控是最后一票否决，AI 给的仓位和置信度都要再过一遍硬约束。

## 快速开始

需要 Python 3.10+。

```bash
git clone https://github.com/ajieun/Stock-simulation-quantitative-trading.git
cd Stock-simulation-quantitative-trading

pip install -r requirements.txt
copy .env.example .env        # Linux/macOS: cp .env.example .env
# 编辑 .env，填入 DEEPSEEK_API_KEY=sk-xxx

python main.py                # 启动浏览器控制台
```

浏览器打开 `http://127.0.0.1:8080`，点右上角「启动引擎」即可开始模拟交易。

没有 DeepSeek Key 也能用：`scan` 和 `backtest` 完全基于规则层，不需要大模型。只有引擎自动决策时才需要 Key。

## 打包成 exe

```bat
build.bat
```

产物在 `dist\AITrader.exe`，单文件约 19 MB，不需要装 Python。打包后配置和数据生成在 exe 同目录。

## 配置

主要参数在 `config.yaml`：

```yaml
mode: paper              # paper = 模拟盘
execution_mode: auto     # auto = 自动模拟撮合 | manual = 只出信号，人工确认

universe:                # 自选池，6 位代码
  - "600519"

strategy:
  min_technical_score: 0.60     # 技术面门槛，调高=交易更少更保守
  min_confidence: 0.66          # AI 置信度门槛
  max_candidates_per_cycle: 3   # 每轮最多问 AI 几只（控制 token）
  ai_min_interval_minutes: 30   # 同一标的重复分析冷却
  no_new_position_after: "14:45"

risk:
  max_position_pct: 0.20        # 单票占总资产上限
  max_total_exposure_pct: 0.80  # 总仓位上限
  max_daily_loss_pct: 0.03      # 当日亏损 3% 停止开仓
  max_drawdown_pct: 0.10        # 回撤 10% 全部暂停
  stop_loss_pct: 0.07           # 硬止损
  take_profit_pct: 0.15         # 硬止盈
  forbid_st: true
```

风控参数是**硬约束**，任何一条不满足就不下单。

`ai.daily_token_budget` 可以限制每天的 token 消耗，超了自动停用 AI，程序退回纯规则层继续跑。

## 策略逻辑

**入场**：8 个因子加权打分（0-1），命中否决项直接淘汰。

| 因子 | 权重 |
|---|---|
| 站上 MA20 | 0.20 |
| 均线多头排列 | 0.15 |
| MACD 红柱放大 | 0.15 |
| RSI 健康区间 45-72 | 0.10 |
| 放量上行 | 0.15 |
| 接近 20 日新高 | 0.10 |
| 短期不过热 | 0.10 |
| 波动率适中 | 0.05 |

否决项：跌破 MA20、MA5 下穿 MA10、MACD 绿柱放大、RSI > 80、量比 < 0.6、放量下跌、5 日涨幅 > 12%、ATR 占比 > 8%。

**离场**：硬止损 / 硬止盈 / 趋势破坏（跌破 MA20 超过 0.5% 且 MA5<MA10）/ 持有超期。

趋势破坏带 0.5% 缓冲，是为了避免价格在均线附近来回穿越时反复买卖、手续费吃光收益——这个坑是回测里发现的。

## 回测

```bash
python main.py backtest --symbols 600519,000001,300750 --days 500
```

回测**不含 AI**：把历史行情喂给大模型有严重前视偏差（训练语料里就有这些走势），所以回测只验证规则层。AI 的效果需要在模拟盘日志里单独评估。

交易假设：当日收盘出信号、次日开盘成交；计费按万分之 2.5 佣金（最低 5 元）+ 卖出印花税千 1 + 过户费十万分之一；T+1。

## 数据来源

- 行情来自东方财富与腾讯网页端公开接口，无需 token，但非官方承诺，字段变更时需要修改 `qtrader/market/quotes.py`
- 交易日历优先用 akshare（装了的话），否则退回内置节假日表，到期需要手动更新
- 所有账户、决策、成交记录都存在本地 `data/trader.db` 和 `logs/`，不上传任何地方

**调用 DeepSeek 时会发送**：行情快照、技术指标、账户总资产与可用资金、持仓数量与成本价。
**不会发送**：任何账号、密码、身份信息。
如果不希望资产规模外发，改 `qtrader/strategy.py` 的 `build_ai_context()`，删掉不想要的字段即可。

## 已知限制

- 回测不含 AI，存在前视偏差风险，回测结果仅代表规则层表现
- 未实现拆单、算法交易、盘中撤单重挂，单笔按最小交易单位整数倍下整单
- 分时数据用日线 + 当日实时快照合成，不做分钟级策略
- 一个进程对应一个模拟账户，未做多账户隔离
- 高价股（如茅台一手十几万）在仓位百分比给得较小时买不起整手，若「一手」仍在单票上限内会按一手买入，否则放弃
- 日亏损基准取自当日首个观测净值，盘中才启动的话早盘涨跌不计入基准
- 交易日历的内置表需要跟着交易所公告更新，建议装 akshare
